# Among-us-numworks
amongus4numworks
🚀 Among Us - NumWorks

Portage du jeu Among Us spécialement conçu pour la calculatrice NumWorks !

📌 Présentation

Retrouvez l'expérience d'Among Us directement sur votre calculatrice NumWorks. Ce projet permet d'exécuter et de jouer à une version adaptée du célèbre jeu de déduction sociale.

🕹️ Installation & Utilisation

Clonez ou téléchargez ce dépôt sur votre ordinateur :

git clone https://github.com/derim00/Among-us-numworks.git


Compilez et chargez le projet sur votre calculatrice NumWorks à l'aide des outils de compilation appropriés (Makefile inclus).
